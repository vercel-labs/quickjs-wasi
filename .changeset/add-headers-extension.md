Add native WASM `Headers` extension implementing the WHATWG Fetch Standard Headers API. Supports constructor (record, sequence, or Headers init), `append`, `delete`, `get`, `getSetCookie`, `has`, `set`, `entries`, `keys`, `values`, `forEach`, and `Symbol.iterator` with spec-compliant case-insensitive name matching, value normalization, sorted iteration, and Set-Cookie handling.
